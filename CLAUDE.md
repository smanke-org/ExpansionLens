# ExpansionLens

Drive the app with `expansionlens` (the app binary; `expansionlens help`). See `.claude/skills/expansionlens/SKILL.md`.
Commands live in `App/Agent/AgentCommands.swift`; test them on a Debug build with `APP_STORE=/tmp/<name>`, which
starts a test copy on its own library and settings with no expansion, shortcuts or sync (Release builds ignore it).
